# Midgard III

Verilog Town: a close replication of the game verilogTown (Jamieson, Grace, Mizuno, Zhang, ASEE 2017).
You write one Verilog module per traffic light; cars drive through a town; Odin III simulates your
modules. It is part of Wyrd III and is started with `midgard`.

- Repository: <https://github.com/drpaj12/wyrd> (package `wyrd/midgard`)
- Manual page: <https://github.com/drpaj12/wyrd/blob/main/docs/user/midgard.md>

How it plugs in: it runs on Bifrost III. Install it with the `midgard` extra of Wyrd III.
